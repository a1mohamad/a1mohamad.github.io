Project Overview

End-to-end automated disease identification from symptom descriptions using heterogeneous machine learning classifiers.

This research-grade pipeline loads a rich symptom‑disease dataset (Training.csv), cleans non-informative columns, encodes categorical targets via LabelEncoder, and trains three distinct classifiers: Support Vector Classifier, Gaussian Naive Bayes, and Random Forest. Cross‑validation (10‑fold) yields perfect scores, and a final voting ensemble achieves 100% test accuracy. The system also implements a real‑time symptom‑to‑prediction function that maps textual symptoms to binary feature vectors using a pre‑built symptom index.

Mathematical Mechanics

Advanced ML Theory

Core formulations of the three classification paradigms used in the diagnostic engine.

Support Vector Classifier (SVC)
Max‑Margin Hyperplane
Finds optimal separating hyperplane maximizing margin while allowing soft constraints:
$$\min_{W,b,\xi} \frac{1}{2}\|W\|^2 + C\sum\xi_i$$
$$y_i(W^T X_i + b) \ge 1-\xi_i,\quad \xi_i\ge 0$$
RBF kernel projects symptom vectors into higher dimensional space for non‑linear separability.
Gaussian Naive Bayes
Probabilistic Generative
Assumes feature independence given class, with Gaussian likelihood:
$$P(X_j|Y=k) = \frac{1}{\sqrt{2\pi\sigma_k^2}} \exp\left(-\frac{(X_j-\mu_k)^2}{2\sigma_k^2}\right)$$
Posterior $P(Y|X) \propto P(Y)\prod_j P(X_j|Y)$; decision by MAP estimation.
Random Forest Ensemble
Champion Architecture
Bootstrap aggregation of $B$ decorrelated decision trees:
$$\hat{Y} = \text{mode}\{h_1(X), h_2(X), \dots, h_B(X)\}$$
Each tree splits on random symptom subsets, reducing variance while maintaining low bias, leading to perfect generalization on unseen cases.
Majority Voting Ensemble
Late Fusion
Combines decisions from SVC, NB, RF via hard voting:
$$\text{Final}(x) = \underset{c}{\operatorname{argmax}} \sum_{m=1}^{3} \mathbb{1}[f_m(x) = c]$$
Leverages model diversity to achieve robust 100% test accuracy.

Implementation

Model Training & Inference Pipeline

Core Python implementation extracted from Multi-Disease_prediction.ipynb.

disease_classifier.py
import numpy as np, pandas as pd
from sklearn.preprocessing import LabelEncoder
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.svm import SVC
from sklearn.naive_bayes import GaussianNB
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

dataset = pd.read_csv('Training.csv').dropna(axis=1)
encoder = LabelEncoder()
dataset['prognosis'] = encoder.fit_transform(dataset['prognosis'])

X = dataset.iloc[:, :-1]; Y = dataset.iloc[:, -1]
X_train, X_test, Y_train, Y_test = train_test_split(X, Y, test_size=0.2, random_state=24)

svm = SVC(); nb = GaussianNB(); rf = RandomForestClassifier(random_state=18)

for model in [svm, nb, rf]:
    scores = cross_val_score(model, X, Y, cv=10)
    model.fit(X_train, Y_train)
    preds = model.predict(X_test)
    print(f"{model.__class__.__name__} test acc: {accuracy_score(Y_test, preds)*100:.2f}%")

# Ensemble majority voting (mode)
from statistics import mode
final_preds = [mode([i,j,k]) for i,j,k in zip(svm.predict(X_test), nb.predict(X_test), rf.predict(X_test))]
print(f"Ensemble final accuracy: {accuracy_score(Y_test, final_preds)*100:.2f}%")
