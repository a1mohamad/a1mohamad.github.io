Ensemble Soft-Voting
Probability Map
$$\hat{p}_j = \frac{1}{N} \sum_{i=1}^{N} w_i p_{ij}$$
Computes the weighted average of predicted class probabilities across all estimators. The final class assignment depends on which combined probability map crosses the target boundary threshold.
Binary Cross-Entropy Loss
Optimization
$$\mathcal{L} = -\frac{1}{M}\sum_{k=1}^{M} [y_k \log(\hat{y}_k) + (1-y_k)\log(1-\hat{y}_k)]$$
The core loss metric minimized during base estimator training, forcing predicted class probabilities to match actual clinical target classifications closely.
