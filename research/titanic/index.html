Project Overview

End‑to‑end pipeline for predicting Titanic passenger survival using neural networks and sophisticated feature engineering.

The sinking of the Titanic remains one of history's most tragic maritime disasters. This project builds a predictive model to determine whether a passenger survived, leveraging passenger data such as age, sex, class, fare, and cabin information. After exploratory data analysis (survival distributions, age analysis, feature correlations), we engineer rich features: title extraction, family size, deck information, ticket group size, cabin wealth, and interaction terms. Missing ages are imputed using an ensemble of LightGBM and Random Forest regressors (60%/40% weight). A neural network with two hidden layers (64/16 neurons, ReLU, L2 regularization, dropout) is trained with 9‑fold stratified cross-validation, achieving an average validation accuracy of 83.05%.

Mathematical Mechanics

Core Algorithms & Theory

Age imputation ensemble and neural network architecture.

Ensemble Age Imputation
LightGBM + RF
Missing ages are predicted using a weighted ensemble of LightGBM (60%) and Random Forest (40%) regressors, trained on engineered features (title, family size, cabin wealth, interaction terms).
$$\hat{y}_{\text{age}} = 0.6 \cdot \text{LGBM}(X) + 0.4 \cdot \text{RF}(X)$$
Predictions clipped to [0, 80].
This approach captures non‑linear relationships and reduces bias compared to simple median imputation.
Neural Network Classifier
Binary Classification
A feed‑forward network with two hidden layers, ReLU activation, L2 regularization, and Dropout for overfitting prevention. Output layer uses sigmoid for probability of survival.
$$h_1 = \text{ReLU}(W_1 x + b_1),\quad h_2 = \text{ReLU}(W_2 h_1 + b_2)$$
$$\hat{y} = \sigma(W_3 h_2 + b_3)$$
Loss: Binary cross‑entropy. Optimizer: Adam (lr=1e-3). Early stopping (patience=5) and ReduceLROnPlateau (factor=0.2) are used.

Conclusions

Project Synthesis & Roadmap

Lessons learned and potential enhancements.

Empirical Breakdown: The engineered feature set (title, family, cabin wealth, social status) significantly improves age imputation and model expressiveness. The neural network with moderate regularization (L2, dropout) prevents overfitting while capturing non‑linear patterns. Stratified 9‑fold cross‑validation provides reliable performance estimates.

Future Directions: Experiment with deeper architectures, hyperparameter tuning via Keras Tuner, incorporate more advanced embedding layers for categorical variables, and deploy the model as a web service. Also, feature selection techniques (SHAP, permutation importance) could reveal dominant survival factors.
