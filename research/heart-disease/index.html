Contextual Briefing

Project Overview

A clinical data-science study focused on predictive risk management for cardiovascular healthcare systems.

This research evaluates statistical approaches to identifying patients at high risk of developing 10‑Year Coronary Heart Disease (CHD). Utilizing an epidemiological dataset of 4,240 records, the framework drops non‑predictive administrative features, handles clinical null entries via systematic feature mean imputation, and maps scaled continuous features to optimized binary probability margins. The core objective is to analyze predictive boundaries by pairing an elemental classification architecture with robust cross‑validation strategies.

Mathematics

Algorithmic Formulations

A mathematical and structural look at the logistic regression classifiers deployed in this clinical study.

Logistic Regression
Baseline
$$P(Y=1|X) = \frac{1}{1 + e^{-(W^T X + b)}}$$
Models the probability of binary outcomes by passing a linear combination of features through the non‑linear Sigmoid activation function.
Logistic Regression CV
Champion
$$\min_{W} \left( \sum_{i=1}^{N} \mathcal{L}(y_i, f(x_i)) + \lambda ||W||^2 \right)$$
An optimized estimator that automates hyperparameter selection via K‑fold cross‑validation across a regularization grid to ensure robust coefficient estimation.

Model Optimization Sandbox

def evaluate_diagnostic_models(x_train, x_test, y_train, y_test):
    # Initialize dual modeling engines to compare base and cross-validated estimators
    models = [
        LogisticRegression(max_iter=10000), 
        LogisticRegressionCV(max_iter=10000)
    ]
    
    for model in models:
        # Fit individual binary logit boundary plane
        model.fit(x_train, y_train)
        
        # Generate operational predictions
        y_pred_test = model.predict(x_test)
        
        # Track metrics inside workspace stream
        print(f"Accuracy: {accuracy_score(y_test, y_pred_test)}")
