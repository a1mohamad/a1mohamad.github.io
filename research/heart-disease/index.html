Project Overview

A clinical data-science study focused on predictive risk management for cardiovascular healthcare systems.

This research evaluates statistical approaches to identifying patients at high risk of developing 10-Year Coronary Heart Disease (CHD). Utilizing an epidemiological dataset comprising 4,240 records, the framework drops non-predictive administrative features, handles clinical null entries via systematic feature mean imputation, and maps scaled continuous features to optimized binary probability margins. The core objective is to analyze predictive boundaries by pairing an elemental classification architecture with robust cross-validation strategies.

Technical Machinery Briefing

A mathematical and structural look at the algorithmic baseline and framework choices powering this project.

Logistic Regression

A fundamental classification algorithm that models the probability of a binary categorical output (Y is either 0 or 1) by passing a linear combination of features through the non-linear Sigmoid Activation function:

P(Y=1|X) = 1 / (1 + e^-(W^T * X + b))

The variant LogisticRegressionCV goes a step further by executing an internal K-fold cross-validation search directly across a defined grid of regularization hyper-parameters to combat model overfitting without leaking test-set data boundaries.

Implementation Sandbox

The structural model validation engine loop built within your Jupyter notebook environment.

def evaluate_diagnostic_models(x_train, x_test, y_train, y_test):
    # Initialize dual modeling engines to compare base and cross-validated estimators
    models = [
        LogisticRegression(max_iter=10000), 
        LogisticRegressionCV(max_iter=10000)
    ]
    
    for model in models:
        # Fit individual binary logit boundary plane
        model.fit(x_train, y_train)
        
        # Generate operational predictions
        y_pred = model.predict(x_train)
        y_pred_test = model.predict(x_test)
        
        # Track metrics inside workspace stream
        print(f"Accuracy: {accuracy_score(y_test, y_pred_test)}")

Project Synthesis

Final verification of data modeling thresholds and strategic evaluation statements.

This project successfully establishes regularized linear boundaries for cardiovascular diagnosis. The Logistic Regression model provided a test set accuracy of 86.63%. Incorporating internal hyperparameter tuning via Logistic Regression CV slightly shifted coefficients to achieve a peak diagnostic test accuracy of 86.71%.

Moving Forward: Future versions should focus on handling data imbalance directly by using class-weight tuning inside the Scikit-Learn classifiers or implementing synthetic oversampling routines to improve positive-class recall scores.
