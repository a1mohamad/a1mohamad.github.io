Model Orchestration & Validation Pipeline

Split-sample validation mapping (70% Train / 30% Test) using scaled feature blocks optimized for regularized logit boundaries.

from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix, accuracy_score

def train_classification_pipeline(x_train, x_test, y_train, y_test):
    # Initialize Regularized Logistic Regression Classifier
    model = LogisticRegression(max_iter=1000)
    model.fit(x_train, y_train)

    # Extract diagnostic predictions
    y_pred_train = model.predict(x_train)
    y_pred_test = model.predict(x_test)
    
    # Performance scores calculation
    train_acc = accuracy_score(y_train, y_pred_train)
    test_acc = accuracy_score(y_test, y_pred_test)
    return model, train_acc, test_acc

Research Synthesis

Final evaluation summary, assessment of the data imbalance challenge, and next architectural upgrades.

The Logistic Regression classifier established a robust diagnostic accuracy baseline of 85% across the cohort test segment. Feature checking indicates that variables such as systolic blood pressure (sysBP), age, and blood glucose levels play a key role in regularized weight estimation.

Next Phase Optimization: Due to the significant imbalance in the target class (3,596 negative vs. 644 positive observations), future work will focus on integrating synthetic oversampling techniques like SMOTE alongside non-linear ensembles (XGBoost, CatBoost) to improve model sensitivity and minority class recall performance.
