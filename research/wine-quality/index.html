Project Overview

An empirical classification pipeline optimizing viniculture grade categorizations using physiochemical attributes.

This research maps complex chemical interactions—such as volatile acidity profiles, density limits, and sulfur structures—to isolate quality variations. Using supervised training models, the pipeline handles missing indices with feature-wide mean updates and scales raw feature matrices using MinMax processing. Quality thresholds are separated into a binary classification variable ($1$ for quality values $> 5$, indicating premium grades, and $0$ otherwise), providing clear target definitions for comparison across different machine learning models.

Advanced Machine Learning Theory

A deep mathematical and conceptual exploration of the core learning architectures deployed in this analysis.

Support Vector Classifier (SVC) with Radial Basis Function

The Support Vector Classifier targets non-linear multi-dimensional separation boundaries by transforming features into higher-dimensional vector spaces where a linear separation boundary becomes possible. Since the interaction of chemical properties like volatile acidity, residual sugar levels, and pH balances is highly interdependent and non-linear, standard linear separating paths often prove insufficient.

This implementation applies the Radial Basis Function (RBF) Kernel, defined mathematically as:

$$K(x, x') = \exp(-\gamma \|x - x'\|^2)$$

Here, $\|x - x'\|^2$ represents the squared Euclidean distance between two data instances, and $\gamma$ is a hyperparameter controlling the radius of influence for individual support vectors. The optimization algorithm seeks to maximize a soft-margin width while applying a regularization penalty parameter ($C$) to manage the balance between training accuracy and generalizability, producing a stable validation baseline of 0.6794.

XGBoost Classifier (Extreme Gradient Boosting Architecture)

XGBoost stands as an optimized distributed gradient boosting framework designed to be highly efficient, flexible, and portable. Unlike traditional ensemble strategies that generate standalone independent decision pathways, gradient tree boosting grows sequential base learners tree-by-tree. Each new tree fits to the negative gradient residuals of the loss function calculated by previous iterations.

The core objective function minimized at iteration $t$ integrates an analytical Taylor expansion loss along with explicit regularization constraints to limit leaf node complexity:

$$\mathcal{L}^{(t)} \approx \sum_{i=1}^{n} \left[ l(y_i, \hat{y}_i^{(t-1)}) + g_i f_t(x_i) + \frac{1}{2} h_i f_t^2(x_i) \right] + \gamma T + \frac{1}{2}\lambda \sum_{j=1}^{T} w_j^2$$

Where $g_i$ and $h_i$ represent the first and second-order gradient statistics of the objective loss function, $T$ denotes the total number of terminal leaf partitions, and $w_j$ indicates the individual leaf score weights. By systematically regularizing complex tree paths, the model manages multi-collinearity among highly correlated inputs like total sulfur dioxide and free sulfur dioxide. This approach achieved top classification scores, reaching a training score of 0.9722 and a test generalizability performance of 0.7833.

Model Optimization Sandbox

Algorithmic implementation tracking feature management, data splitting, and model processing.

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import MinMaxScaler
from sklearn.svm import SVC
from xgboost import XGBClassifier
from sklearn.linear_model import LogisticRegression
from sklearn import metrics

def evaluate_wine_models(data_path):
    '''
    Loads wine dataset, creates a binary target variable, applies mean imputation,
    and runs comparative training across multiple model classifiers.
    '''
    # Read structural feature matrix from current workspace path
    df = pd.read_csv(data_path)
    
    # Define binary classification cutoff target threshold (1 if quality > 5 else 0)
    df['best quality'] = [1 if x > 5 else 0 for x in df.quality]
    
    # Handle features alignment and replace missing entries with feature means
    features = df.drop(columns=['quality', 'best quality'])
    features = features.fillna(features.mean())
    target = df['best quality']
    
    # Create train/test partitions using a deterministic random state splits execution
    xtrain, xtest, ytrain, ytest = train_test_split(
        features, target, test_size=0.2, random_state=50
    )
    
    # Scale features using a MinMax transformation sequence bounded between 0 and 1
    scaler = MinMaxScaler()
    xtrain = scaler.fit_transform(xtrain)
    xtest = scaler.transform(xtest)
    
    # Enumerate through target evaluation models array loop
    models = [LogisticRegression(), XGBClassifier(), SVC(kernel='rbf')]
    
    for i in range(len(models)):
        # Fit individual model constraints on scaled training subsets
        models[i].fit(xtrain, ytrain)
        
        train_preds = models[i].predict(xtrain)
        test_preds = models[i].predict(xtest)
        
        print(f'{models[i].__class__.__name__}:')
        print('Training Accuracy (ROC-AUC):', metrics.roc_auc_score(ytrain, train_preds))
        print('Validation Accuracy (ROC-AUC):', metrics.roc_auc_score(ytest, test_preds))

if __name__ == "__main__":
    evaluate_wine_models('./dataset/wine_quality.csv')
