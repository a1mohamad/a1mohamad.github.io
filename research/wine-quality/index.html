Project Overview

An empirical classification pipeline optimizing viniculture grade categorizations using physiochemical attributes.

This research maps complex chemical interactions—such as volatile acidity profiles, density limits, and sulfur structures—to isolate quality variations. Using supervised training models, the pipeline handles missing indices with feature-wide mean updates and scales raw feature matrices using MinMax processing. Quality thresholds are separated into a binary classification variable (1 for quality values > 5, indicating premium grades, and 0 otherwise), providing clear target definitions for comparison across different machine learning models.

Advanced Machine Learning Theory

A deep mathematical and conceptual exploration of the core learning architectures and metric diagnostics deployed in this analysis.

Support Vector Classifier (RBF Kernel)

Applies the Radial Basis Function Kernel to map chemical attributes into higher-dimensional vector spaces, defining a complex non-linear separation boundary:

$$K(x, x') = \exp(-\gamma \|x - x'\|^2)$$

This transformation allows the classifier to identify non-linear relationships between acidic profiles and quality, maximizing the geometric margin between standard and premium wine classes.

XGBoost Classifier Architecture

An optimized gradient boosting framework that builds sequential decision pathways, minimizing the objective loss function via second-order Taylor expansion:

$$\mathcal{L}^{(t)} \approx \sum_{i=1}^{n} \left[ g_i f_t(x_i) + \frac{1}{2} h_i f_t^2(x_i) \right] + \gamma T + \frac{1}{2}\lambda \sum_{j=1}^{T} w_j^2$$

By regularizing tree complexity and gradients, it achieves superior generalizability across multi-collinear inputs, yielding a validation AUC of 0.7833.
