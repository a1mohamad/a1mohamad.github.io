Project Overview

An empirical classification pipeline optimizing viniculture grade categorizations using physiochemical attributes.

This research maps complex chemical interactions—such as volatile acidity profiles, density limits, and sulfur structures—to isolate quality variations. Using supervised training models, the pipeline handles missing indices with feature-wide mean updates and scales raw feature matrices using MinMax processing. Quality thresholds are separated into a binary classification variable ($1$ for quality values $> 5$, indicating premium grades, and $0$ otherwise), providing clear target definitions for comparison across different machine learning models.

Classification Infrastructure

A comparative look at the core machine learning models evaluated during this study.

Support Vector Classifier (SVC)

Employs Radial Basis Function (RBF) kernels to project scaled chemical variables into high-dimensional space boundaries. SVC searches for optimal separating hyperplanes that maximize decision margins between target quality boundaries, yielding a baseline testing accuracy score of 0.6794.

XGBoost Classifier (Extreme Gradient Boosting)

An optimized, scalable tree-boosting framework that builds sequential decision trees to minimize gradient residuals. It uses regularization to control model complexity and avoid overfitting. This approach achieved top classification scores, reaching a training accuracy of 0.9722 and a test performance of 0.7833.

Model Optimization Sandbox

Algorithmic implementation tracking feature management, data splitting, and model processing.

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import MinMaxScaler
from sklearn.svm import SVC
from xgboost import XGBClassifier
from sklearn.linear_model import LogisticRegression
from sklearn import metrics

def evaluate_wine_models(data_path):
    '''
    Loads wine dataset, creates a binary target variable, applies mean imputation,
    and runs comparative training across multiple model classifiers.
    '''
    df = pd.read_csv(data_path)
    
    # Define binary classification cutoff target
    df['best quality'] = [1 if x > 5 else 0 for x in df.quality]
    
    features = df.drop(columns=['quality', 'best quality'])
    features = features.fillna(features.mean())
    target = df['best quality']
    
    xtrain, xtest, ytrain, ytest = train_test_split(features, target, test_size=0.2, random_state=40)
    
    # Scale the feature matrices
    scaler = MinMaxScaler()
    xtrain = scaler.fit_transform(xtrain)
    xtest = scaler.transform(xtest)
    
    models = [LogisticRegression(), XGBClassifier(), SVC(kernel='rbf')]
    for i in range(3):
        models[i].fit(xtrain, ytrain)
        print(f'{models[i]}:')
        print('Training Accuracy: ', metrics.roc_auc_score(ytrain, models[i].predict(xtrain)))
        print('Validation Accuracy: ', metrics.roc_auc_score(ytest, models[i].predict(xtest)))
