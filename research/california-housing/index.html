Project Overview

An empirical regression pipeline predicting median house values based on census block district statistics.

This project leverages the classic California Housing dataset to predict median house values (in units of $100,000$). The feature space comprises metrics including median income, house age, average room counts, and geographic coordinates. We employ a Linear Regression model to map these independent variables to the target output, establishing a robust baseline for predicting real estate market valuation.

Regression Theory & Metrics

Multiple Linear Regression

Linear regression models the relationship between a dependent variable $y$ and one or more independent variables $X$ by fitting a linear equation to observed data. The hypothesis function is defined as:

$$\hat{y} = \beta_0 + \beta_1x_1 + \beta_2x_2 + \dots + \beta_nx_n + \epsilon$$

Performance Metrics (MSE & MAE)

To evaluate the model's predictive accuracy, we utilize two primary metrics:

Mean Squared Error (MSE): Penalizes larger errors by squaring the differences between predicted and actual values:

$$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

Implementation

'''
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, mean_absolute_error

def train_and_evaluate(x_train, x_test, y_train, y_test):
    # Algorithm: Linear Regression
    reg_model = LinearRegression()
    reg_model.fit(x_train, y_train)

    # Predictions
    y_pred = reg_model.predict(x_test)
    
    # Metrics calculation
    mse = mean_squared_error(y_test, y_pred)
    mae = mean_absolute_error(y_test, y_pred)
    return mse, mae

Project Conclusion

This research confirms Linear Regression as a suitable baseline for the California Housing dataset. With an MSE of 0.548 and MAE of 0.538, the model effectively explains the variance in housing prices.

Moving Forward: To capture local anomalies and luxury market fluctuations, future versions should explore non-linear ensemble methods like XGBoost or Gradient Boosting Regressors.
